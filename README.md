# SIM - Security Incident Mapping

## Project Overview
SIM (Security Incident Mapping) is a web-based platform designed to help students, staff, and landlords report security incidents within and around the campus community.

## Aim
The aim of this project is to contribute to reducing campus crime by making security incident reporting easier and faster.

## Target Users
- Students
- Staff
- Landlords

## Main Features
- Security incident reporting form
- Incident type selection
- Incident location description
- Incident date and time
- Incident review by an administrator

## Technologies
- HTML
- CSS
- JavaScript
